## Snippet 2 — Spawn logic

```csharp
private void SpawnParticles()
{
    particles = new Particle2D[TotalParticles];

    int index = 0;

    float gridWidth = (numToSpawn.x - 1) * particleSpacing;
    float gridHeight = (numToSpawn.y - 1) * particleSpacing;

    Vector2 origin = spawnCenter - new Vector2(gridWidth * 0.5f, gridHeight * 0.5f);

    for (int y = 0; y < numToSpawn.y; y++)
    {
        for (int x = 0; x < numToSpawn.x; x++)
        {
            Vector2 position = origin + new Vector2(x * particleSpacing, y * particleSpacing);
            particles[index] = new Particle2D
            {
                position = position,
                velocity = Vector2.zero,
                density = 0f,
                pressure = 0f
            };
            index++;
        }
    }
}
```

## Snippet 3 — Brute-force neighbor search

```csharp
private void FindNeighbors()
{
    int n = particles.Length;

    neighbors = new List<int>[n];

    for (int i = 0; i < n; i++)
    {
        neighbors[i] = new List<int>();

        for (int j = 0; j < n; j++)
        {
            if (i == j) continue;

            float dist = Vector2.Distance(particles[i].position, particles[j].position);

            if (dist < smoothingLength)
            {
                neighbors[i].Add(j);
            }
        }
    }

    for (int i = 0; i < n; i++)
    {
        Debug.Log($"Particle {i}: {neighbors[i].Count} neighbors");
    }
}
```

**Explain:**
- What is the outer loop doing? outer loop first iterate each particles.
- What is the inner loop doing? innerloop is for compararing the particle that outer loop iterate with the one that are iterate in innerloop
- Why do we skip `i == j`? because we are iterating the same array so if i = j its basically the same particle 
- What does `neighbors[i]` contain after this method finishes? it will have list neighbors that particle i have.
- Is the neighbor relationship symmetric? Why or why not? yes its symmetric because the function search by the radius. because if distance between a and b is 5, then distance between b and a also 5, thats why its symmetric.
- What is the time complexity of this approach? its N^2 because of the two loop
