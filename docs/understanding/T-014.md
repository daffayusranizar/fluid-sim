Detailed formulas:

Density formula:
```
ρ_i = Σ_j m_j * W_poly6(|r_i - r_j|, h)
```

Pressure formula (Tait EOS):
```
p_i = k * (ρ_i - ρ_0)
```
- `ρ_0` = rest density (target density)
- `k` = stiffness constant

Pressure force formula:
```
F_pressure_i = -Σ_j m_j * (p_i + p_j) / (2 * ρ_j) * ∇W_spiky(|r_i - r_j|, h)
```

Viscosity force formula:
```
F_viscosity_i = μ * Σ_j m_j * (v_j - v_i) / ρ_j * ∇²W_visc(|r_i - r_j|, h)
```

Integration formulas (Semi-Implicit Euler):
```
a_i = F_total_i / ρ_i
v_i += a_i * dt
x_i += v_i * dt
```

Per-particle vs pairwise:
- Per-particle: pressure `p_i`, integration `v_i`/`x_i`
- Pairwise: density `ρ_i`, pressure force, viscosity force
