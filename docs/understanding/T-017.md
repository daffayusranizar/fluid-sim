## Snippet 2 — Pressure computation

```csharp
private void ComputePressure()
{
    for (int i = 0; i < particles.Length; i++)
    {
        particles[i].pressure = stiffness * (particles[i].density - restDensity);
    }
}
```

**Explain:**
- Why is pressure computed per-particle and not pairwise? because now we only want to compte the pressure that each particle have, later we will compute the pressure of the area pairwise.
- What does `(density - restDensity)` represent physically? it represent the difference of density right now and the target density 
- What is the sign of pressure when density is above rest density? Below? If density > restDensity: (density - restDensity) is positive → pressure is positive. If density < restDensity: (density -   restDensity) is negative → pressure is negative. Positive pressure pushes outward; negative pressure pulls inward. 
- Why is this called an "equation of state"? It’s called an equation of state because it defines how one state variable (pressure) is determined by another (density), just like the ideal gas law PV = nRT relates pressure, volume, and temperature.

## Snippet 4 — Where pressure fits in Update

```csharp
FindNeighbors();
ComputeDensity();
ComputePressure();
// ComputeForces() will come later
```

**Explain:**
- Why must pressure come *after* density? density is the foundation of the pressure computation. we need to know how dense the area is to compute the pressure
- Why must pressure come *before* forces? pressure is the one that make the force. so we have to know the pressure first, then compute the force that created by the pressure.
- What happens to the simulation if `stiffness` is too low? Too high? if its too low then the particle will be compressed, if its too high it will repel each other hard.

## Final reflection

1. Why does SPH derive pressure from density instead of simulating pressure directly? because simulating pressure directly is expensive, rather than doing the global computing, sph only do it on the particle.
2. What does it mean physically for a fluid to be "weakly compressible"? to make the particle really incompressable is expensive weh need to solve global constraint, but with weakly compressible we can allow it to be weakly compressable about one to five percent, so we use stiff equation to make the compression minimal.
3. If `restDensity = 1000` and `particleMass` is doubled for the same spacing, what happens to pressure? Why? Doubling particleMass at the same spacing doubles the computed density. Since restDensit is unchanged, (density - restDensity) becomes large and positive, so pressure spikes. The high pressure then pushes particles apart until the density drops back toward restDensity.
4. Why is the Tait EOS used instead of something more complex like solving a Poisson equation for incompressibility? because we want to avoid the global solve and linear system. we want it to be particle scope not the global ones
